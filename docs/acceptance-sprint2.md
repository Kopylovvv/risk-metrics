# Контрольная приёмка второго показа

Задача #32. Полный цикл «рыночные параметры → стоимость позиции → DV01 → сохранённый
результат» через HTTP API, с записанным результатом и происхождением каждого числа.

## Как воспроизвести

```bash
docker compose up -d --wait db                 # из корня
cd backend
alembic upgrade head
python -m app.stubs.demo_data                  # демо-параметры на сегодня
uvicorn app.main:app --reload                  # на Windows обязательно --reload
python scripts/acceptance.py                   # в соседнем терминале
```

Скрипт `backend/scripts/acceptance.py` проходит сценарий из backend/README («Показ:
backend по шагам») и сверяет каждое число с ручным расчётом. Код выхода 0 — всё совпало.

## Записанный результат (26.10.2026)

Версия: коммит `84a81a7` (main после #43, #44), методика `dv01-v2`, дата оценки
2026-10-26, параметры — демо-данные `app/stubs/demo_data.py` (провайдер `test`),
внешние источники не подключены.

```

  [OK] backend и БД доступны: {'status': 'ok', 'database': 'ok'}

  [OK] RU000A0JX0J2: MISSING_MARKET_DATA, значение null, не 0
```

численно они равны ожидаемым.

## Происхождение каждого числа

| Число | Откуда | Как проверено |
|---|---|---|
| CFV 96 250 | 100 × (1000 × 95 % + НКД 12.5) | вручную; `test_risk_core`, `test_api_calculations` |
| DV01 −28.869225 | 96 250 × (−3 × 0.0001 + ½ × 12 × 0.0001²) | вручную, тот же пример в тестах ядра |
| CFV 300 495, DV01 −7.512375 | флоатер: D = 1/4, C = 0; 299 × 1005 × (−0.000025) | вручную, правило ТЗ |
| CFV −920 606.25, DV01 +386.53954921875 | шорт 10 × (985 + 10.25) × курс 92.5; D 4.2, C 25 | вручную, знак шорта положительный |
| итог 350.15794921875 | сумма трёх строк | вручную |
| `MISSING_MARKET_DATA` | у fixed-бумаги нет дюрации | ошибка строки, значение `null` |
| `PROVIDER_UNAVAILABLE` | бумаги нет в БД, источник не подключён | при доступе к Cbonds будет `INSTRUMENT_NOT_FOUND` |

Параметры бумаг демонстрационные (не рыночные). Независимого эталона эксперта с
допустимым отклонением пока нет — см. «Блокеры».

## Демонстрация ошибок

- Нет параметров для формулы → строка `failed`, `MISSING_MARKET_DATA`, итога нет (`partial`).
- Бумага неизвестна / источник недоступен → `PROVIDER_UNAVAILABLE` или `INSTRUMENT_NOT_FOUND`.
- Набор изменили параллельно → `409 REVISION_CONFLICT`, ничего не сохраняется.
- Сквозные проверки ошибок источника Cbonds (таймаут, 401/403/500, несовместимые данные) —
  `tests/test_market_data_cbonds.py`, `tests/test_control_examples.py` (PR #46, #47).
