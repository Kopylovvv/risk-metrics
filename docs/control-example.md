# Контрольный пример и план проверок DV01

Задачи #15 и #31. Все ожидаемые значения посчитаны вручную и закреплены в тестах.
Это **учебный** пример: эталон эксперта с допустимым отклонением ещё не получен.

## Формула (методика `dv01-v2`)

```
CFV  = количество × (номинал × цена% / 100 + НКД) × курс к рублю
DV01 = CFV × (−D × 1bp + ½ × C × 1bp²),  1bp = 0.0001
floating: D = 1 / выплат в год, C = 0
итог по набору = Σ DV01 строк (только если все строки посчитаны)
```

Округления нет. Лонг даёт DV01 < 0, шорт — DV01 > 0.

## План проверок

| Требование / ошибка | Проверка | Ожидание | Тест |
|---|---|---|---|
| формула fixed, знак лонг/шорт | контрольные примеры | значения из таблицы | `test_risk_core`, `test_control_examples` |
| правило floating | D = 1/частота, C = 0, дюрация источника игнорируется | −1.25675 | `test_floating_coupon_uses_tz_rule` |
| валютная бумага | CFV в рублях по курсу | +231.02… | `test_control_set_from_cbonds_to_saved_result` |
| несколько сделок | итог = Σ DV01 | 209.464523609375 | там же |
| нет дюрации/выпуклости у fixed | ошибка строки | `MISSING_MARKET_DATA`, значение `null` | `test_missing_duration_or_convexity` |
| нет торгов с ценой | ошибка строки | `MISSING_MARKET_DATA`, итог `null`, статус `partial` | `test_errors_are_not_replaced_by_zero` |
| бумаги нет у источника | ошибка строки | `INSTRUMENT_NOT_FOUND` | там же |
| несовместимые данные | чужой ISIN, дата позже, валюта, ≤ 0, NaN | `INCOMPATIBLE_MARKET_DATA` | `test_incompatible_data` |
| источник недоступен | 500, таймаут, 401/403 | `PROVIDER_UNAVAILABLE`, статус `failed` | `test_source_down_is_not_a_financial_error`, `test_provider_unavailable` |
| данные уже в БД | повторный расчёт не ходит к источнику | тот же итог | `test_saved_data_is_reused_without_source` |
| изменение сделки | старый расчёт не меняется | входы на момент расчёта | `test_history_keeps_own_inputs_after_trade_changes` (backend) |
| второй источник (RuData) | — | не проверяется: доступа нет | — |

Отсутствие данных нигде не заменяется нулём: у ошибочной строки `metric_value = null`,
у набора с ошибками `total_value = null`. Все проверки работают без сети (CI).
