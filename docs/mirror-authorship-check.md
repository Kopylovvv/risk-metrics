# Проверка авторства и зеркалирования

Тестовая ветка для проверки одного и того же коммита на GitHub и GitLab МАИ.

Проверяем:
- email автора соответствует адресу университетского аккаунта;
- GitHub связывает коммит с личным профилем автора;
- GitLab получает тот же коммит с неизменным идентификатором и автором.

Результат проверяется по данным площадок после отправки коммита.
