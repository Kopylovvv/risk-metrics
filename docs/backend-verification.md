### Два независимых посетителя

| Действие посетителя B над набором A | Ответ |
|---|---|
| чтение набора, добавление, изменение, удаление сделки, расчёт | 404 `WORKSPACE_NOT_FOUND` |
| чтение расчёта A и `source-diff` | 404 `CALCULATION_NOT_FOUND` |
| CSRF-токен A с cookie B | 403 `CSRF_TOKEN_INVALID` |
| запрос без cookie | 401 `SESSION_REQUIRED` |

B видит только свой пустой набор и меняет только его; revision, сделки и расчёт A после
этого прежние.

### Revision и история

* Со старым revision изменение, добавление, удаление и расчёт дают 409
  `REVISION_CONFLICT`, набор не меняется.
* После правки количества 100 → 200 и новой загрузки на следующий день (цена 96%) старый
  расчёт отдаёт прежний ответ байт в байт: количество 100, цена 95, дата 13.11.2026.
  `source-diff` показывает отличие только в `price_pct`.
* Удаление сделки обнуляет `trade_id` в строке истории, значения остаются.
* UPDATE сохранённых снимков, курсов и результатов БД запрещает (миграция 0005).
