# Доступ команды к стенду

Приложение: https://teahorses.mhimf.net/ .

По решению владельца от 18.11.2026 команда использует существующую учётную запись
`teahorses` с административным sudo. Отдельные пользователи и ограничения по ролям
не вводятся: участникам нужен доступ к разным компонентам приложения.

У каждого участника должен быть собственный SSH-ключ. Приватные ключи не
передаются коллегам. Публичные ключи устанавливаются отдельными строками в
`/home/teahorses/.ssh/authorized_keys` (600, каталог `.ssh` — 700).

| Участник | Логин VM | Состояние ключа |
|---|---|---|
| Александр Копылов | teahorses | Вход проверен |
| Семён Сабетов | teahorses | Публичный ключ установлен, личное подтверждение ожидается |
| Андрей Вольвач | teahorses | Ожидается публичный ключ |
| Егор Михайлов | teahorses | Ожидается публичный ключ |

```bash
ssh -i ~/.ssh/<свой-ключ> teahorses@158.160.170.45
cd ~/risk-metrics
sudo docker compose ps --all
sudo docker compose logs --tail=100 backend frontend migrate
git rev-parse HEAD
curl --fail http://127.0.0.1:8080/health/ready
```

Этот доступ позволяет менять приложение, читать секреты и управлять БД и другими
сервисами VM. Общий системный пользователь не позволяет надёжно различать авторов
команд. Любые изменения стенда согласуются с командой; checkout приложения меняет
автодеплой. Не запускать `docker compose down -v` на стенде.

Просмотр мониторинга через отдельный терминал:

```bash
ssh -N -L 3000:127.0.0.1:3000 -L 9090:127.0.0.1:9090 -i ~/.ssh/<свой-ключ> teahorses@158.160.170.45
```

Grafana открывается по http://127.0.0.1:3000/ , Prometheus — http://127.0.0.1:9090/ .
Пароль Grafana передаётся владельцем отдельно. Дашборд имеет UID `risk-metrics`.

Для отзыва доступа удалить соответствующую публичную строку из `authorized_keys`
и завершить сессии участника. Поскольку всем доступен sudo, такой отзыв эффективен
только при доверии к оставшимся администраторам. После установки ключа каждый
участник подтверждает в #56 дату и успешный личный вход. Установка ключа и личная
проверка фиксируются раздельно.
